
# Student Management System

A full-stack Student Management System built using the MERN stack.

## Technologies Used

- React.js
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Bootstrap

## Features

### Admin
- Student Management
- Faculty Management
- Subject Management
- Marks Management
- Attendance Management

### Faculty
- Faculty Login
- Student Management
- Attendance Management
- Marks Management

### Student
- Student Login
- Student Profile
- Change Password
- View Attendance
- Overall Attendance Percentage
- Attendance Warning
- Semester-wise Marks
- Report Card
